# 市場分析：PostLift AI

## 1. なぜShopifyポスト購入アップセルなのか

### EC自動化全体での位置づけ

「AI＋電気代＋API代だけで全自動で回す」という要件に対し、次の4市場を比較した。

1. Shopify向けCVR/AOV改善アプリ
2. 歯科向け患者リコール自動化
3. 建設見積/現場原価系
4. 汎用SMB AI自動化

### 選定フレーム（7軸）

| 軸 | 定義 |
|----|------|
| 痛みの頻度 | 毎週・毎日発生する課題か |
| 金への近さ | 売上・請求・収益に1クリックで近いか |
| 導入速度 | 14日トライアルで効果が見えるか |
| 継続性 | 解約されにくい月額課金が成立するか |
| 競合密度 | 既存巨人に潰されないニッチがあるか |
| 実装難易度 | 個人で90日MVPが作れるか |
| 配布導線 | App Storeや業界コミュニティ等の到達経路があるか |

## 2. 候補市場の詳細評価

### ① Shopify CVR/AOV改善アプリ（採用）

**市場規模・成長性**
- Shopifyは2026年時点でグローバルに数百万ストアを抱え、App Storeは実質的な流通チャネル
- AOV改善カテゴリ（アップセル/クロスセル）はShopify App Storeでも上位カテゴリのひとつ
- D2Cブランドのポスト購入体験への投資は成長傾向

**差別化ポイント**
- 既存ツール（ReConvert、Zipify OCU等）はルールベースが多く、粗利・在庫・承諾率を統合した最適化が弱い
- 「AOV uplift」ではなく「Margin-adjusted uplift」で価値訴求する点が差別化になる

**リスク**
- 競合多数（ただし細分化されており、特化で勝てる余地がある）
- Shopify APIの仕様変更リスク

### ② 歯科向け患者リコール自動化

**評価**
- 痛みは深い（患者連絡、再来院、リマインドは毎週発生）
- チャーンが低い（業務に組み込まれると離れにくい）
- ただし、HIPAA等の業界規制対応、既存PMSとの連携、B2Bセールスサイクルが長い
- 個人MVPとしては最初には重い

### ③ 建設見積/現場原価系

**評価**
- 痛みは極めて深い
- ただし導入期間3〜6か月、会計連携・ローカル資材DB等が必要
- 初速が遅く、個人1人目の顧客獲得が難しい

### ④ 汎用SMB AI自動化

**評価**
- 一番作りやすいが一番埋もれやすい
- 「なぜこのツールか」の答えが出しにくい
- 短期で差別化を維持するのが困難

## 3. Shopifyカテゴリ内の絞り込み

### AOV改善メカニズム5種

| メカニズム | 難易度 | 効果 | MVP適性 |
|------------|--------|------|----------|
| カート内アップセル | 中 | 中〜高 | ○ |
| 送料無料閾値 | 低 | 中 | ◎ |
| バンドル | 中 | 高 | ○ |
| **ポスト購入ワンクリックアップセル** | **中** | **高** | **◎** |
| 保証/保険アドオン | 高 | 高 | △ |

### ポスト購入アップセルを選ぶ理由

1. 購入後なのでストア体験本体を壊しにくい
2. 追加提案の成否が測りやすい（accept/reject の2択）
3. 既存カテゴリはあるが「粗利補正＋AI最適化」は未開拓
4. 価値訴求が明快：「導入後AOVが何％上がったか」で売れる
