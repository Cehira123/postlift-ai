# PostLift AI 販売ページ案

## Shopify向けポスト購入アップセル機能を、自分で運用できるコード商品として

PostLift AIは、Shopifyの購入後アップセル機能を作るための自己ホスト型コードテンプレートです。

ShopifyアプリのOAuth、Webhook、商品同期、オファー生成、メトリクス表示、PostgreSQL保存、テストコードまで含まれているため、ゼロから実装するより早く、Shopify向けアップセル機能の土台を作れます。

これは月額SaaSではありません。購入者自身のShopifyアプリ、サーバー、データベースで動かすためのソースコード商品です。

## こんな人向けです

- Shopifyアプリ開発の実装例がほしい開発者
- Shopify案件を受ける制作会社・個人開発者
- 自社ストア向けにアップセル機能を試したい技術者
- OAuth、Webhook、商品同期、PostgreSQL設計をまとめて参考にしたい人
- 公開SaaSではなく、自分の管理下で動かしたい人

## できること

- Shopifyアプリのインストール/OAuthフロー
- Shopify Admin APIを使った商品同期
- 商品の価格、粗利、在庫、承諾率を使ったアップセル候補の選定
- 購入後オファーを返すAPI
- オファーの承諾/拒否の記録
- メトリクス表示用API
- PostgreSQLへの保存
- Shopify WebhookのHMAC署名検証
- Privacy/GDPR系Webhookの受け口
- Railway/Render/Docker向けのデプロイ構成
- ローカルE2Eテスト

## 含まれるもの

- FastAPIバックエンド
- Shopify post-purchase UI extensionの雛形
- PostgreSQLスキーマとマイグレーション
- 商品同期ロジック
- オファー生成ロジック
- メトリクスAPI
- ダッシュボード用テンプレート
- Webhook署名検証
- テストコード
- 自己ホスト用セットアップ手順
- 購入者が行うべき設定と責任範囲の説明

## 含まれないもの

- 運営代行
- サーバー代・DB代・API利用料
- Shopify App Storeの審査通過保証
- Protected Customer Dataの承認保証
- 法務、税務、プライバシー対応の代行
- 本番ストアの運用サポート
- 売上向上の保証

本商品は「完成済みSaaS」ではなく、「購入者が自己責任で構築・運用するためのコードベース」です。

## なぜ自己ホスト型なのか

Shopifyアプリを公開SaaSとして運営する場合、技術以外にも多くの実務が必要になります。

- Shopify審査
- 個人情報・注文情報の管理
- プライバシーポリシーや利用規約
- 問い合わせ対応
- サーバー監視
- 課金・返金対応
- 障害対応

PostLift AIは、そこまでの運営責任を含めたサービスではありません。

あくまで「Shopify向けアップセル機能を作るための技術的な土台」を提供します。購入者は自分のアカウント、自分のDB、自分のShopifyアプリとして構築できます。

## 動作確認済みの範囲

現在のコードでは、以下の流れを確認済みです。

- APIの起動
- PostgreSQL接続時のヘルスチェック
- ShopifyアプリのOAuthリダイレクト
- 商品同期
- 署名付きWebhookによるオファー作成
- `/offers/current` によるオファー取得
- オファー承諾/拒否の記録
- メトリクス更新
- ローカルE2Eテスト
- 公開URLに対するスモークテスト

## 購入後の流れ

1. ソースコードを受け取る
2. `README.md` を読む
3. `.env.example` を参考に環境変数を設定する
4. PostgreSQLを用意する
5. スキーマとマイグレーションを適用する
6. Shopify Partnerで自分のアプリを作る
7. ShopifyのAPIキー、シークレット、Webhookシークレットを設定する
8. Railway、Render、DockerなどでAPIを公開する
9. 開発ストアにインストールして商品同期を試す
10. テストWebhookまたは開発ストアのテスト注文で動作確認する

## 重要な注意点

Shopifyの本番環境で、注文履歴、顧客情報、購入後拡張機能などを扱う場合、Shopify側の追加承認が必要になることがあります。

この承認は購入者自身のShopifyアプリに対して行うものです。販売者が承認を保証するものではありません。

本商品は、学習用、検証用、開発の土台、または購入者自身のプロジェクトへの組み込みを想定しています。
